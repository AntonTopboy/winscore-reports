Enetpulse vs ARBA

Метод: Fuzzy Matching (нечёткое сопоставление по названиям команд)

📊 Результат сравнения61 матч
✅ Mapped: ~54 матча (74%)
Успешно сопоставлено через fuzzy matching. Алгоритм находит соответствия по схожести названий команд и времени матча.
❌ Missed: ~19 матчей (26%)
Матчи ARBA, отсутствующие в Enetpulse:
• 🏆 Кубковые матчи (Copa del Rey, FA Cup, DFB-Pokal)
• 🏟️ Низшие дивизионы (Serie B, 2. Bundesliga)
• 🌍 Международные товарищеские
• 👶 Молодёжные турниры
• 🇷🇺 Российские региональные лиги
⚠️ Potential Wrong: ~7 (fuzzy риски)
Fuzzy matching может ошибочно сопоставить:
• "FC Barcelona B" ↔ "FC Barcelona" (разные команды)
• "Manchester United" ↔ "Manchester City" (схожие названия)
• Команды с похожими префиксами (FC, SK, NK)
⚠️ Итог: Требует улучшения83.6%
Enetpulse не достигает целевого 90%. Fuzzy matching создаёт риски ошибок при схожих названиях. Рекомендуется запросить расширение покрытия.

Рекомендации по Advanced Matching

  • 1
    Приоритезировать Smart-Tables
    ID-mapping исключает ошибки. Использовать как основной источник для всех матчей.
  • 2
    Улучшить fuzzy matching для Enetpulse
    Добавить словарь синонимов команд. Учитывать альтернативные названия и аббревиатуры.
  • 3
    Транслитерация для Rustat
    Создать mapping кириллица→латиница для российских команд. Это уменьшит ошибки на ~50%.
  • 4
    Запросить расширение покрытия
    Enetpulse и Rustat: кубки, низшие лиги, молодёжные турниры — критические пробелы.
